# ⚡ ¡Hola! Soy María José Brito
### Estudiante de Ciencias de la Computación | Apasionada por el Machine Learning & el Impacto Social

Actualmente curso el noveno ciclo de Ciencias de la Computación en la Universidad de Cuenca. Me dedico a investigar y desarrollar soluciones tecnológicas que integren **Data Science, Big Data y Machine Learning** con un fuerte enfoque en el monitoreo ético, la privacidad y la inclusión social.

- **Proyecto Central / Tesis:** `MoViFed` — Un framework multimodal de aprendizaje federado para la detección de seguridad doméstica en dispositivos edge.
- **Áreas de Enfoque:** Aprendizaje supervisado/no supervisado, arquitecturas distribuidas y analítica predictiva.
- **Diseño UI/UX:** Creación de prototipos móviles de alta fidelidad bajo un enfoque estético minimalista.
- **Ubicación:** Cuenca, Ecuador
